# **Project Requirements Document: ERP Activity Management Module**

The following table outlines the detailed functional requirements for the Activity Management module of the ERP system.

| Requirement ID | Description                      | User Story                                                                                      | Expected Behavior/Outcome                                                                                                                                                    |
|----------------|----------------------------------|--------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FR001          | Creating a New Task              | As a user, I want to create a task with various fields depending on the type (mail or task).     | The system should display a form with fields: `label`, `observation`, `status`, `type`, and auto-filled `creation_date` and `department`. For `mail` type, it should also show `sender`, `receiver`, and allow mail scan upload. Report file upload should be available for all types. Uploaded files must be stored in Firebase Storage, and their URLs saved in Firestore. |
| FR002          | Viewing Task Details             | As a user, I want to view all details of a task in a dedicated detail page.                     | Upon selecting a task, the user should be navigated to a detail view showing all task information and preview options for any uploaded documents.                           |
| FR003          | Editing a Task                   | As a user, I want to edit any of the fields of an existing task.                                | The system should allow editing of task fields directly in the detail view and update the Firestore document and storage URLs accordingly.                                  |
| FR004          | Listing Department Tasks         | As a user, I want to view all tasks related to my department and filter them.                   | The system should show a list of tasks where `department == user.department`, and support filtering by `status` and `type`.                                                  |
| FR005          | Deleting a Task                  | As a user, I want to delete a task and confirm before it is permanently removed.                | When delete is triggered, the system should prompt a confirmation dialog. If confirmed, the task is deleted from Firestore and any associated files from Firebase Storage.  |
| FR006          | Viewing All Tasks (Admin)        | As an admin, I want to see tasks from all departments and filter them.                          | Admin users should access a full list of all tasks across departments with filter options for `status` and `type`.                                                           |
| FR007          | Viewing Task Details (Admin)     | As an admin, I want to view the detailed information of any task.                               | Admins can view any task in detail with full visibility of uploaded documents and metadata.                                                                                  |
